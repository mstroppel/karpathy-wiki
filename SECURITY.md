# Security Policy

## Supported Versions

Security fixes are applied to the latest released version. Pin a release in
production and monitor GitHub releases and Dependabot alerts.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting for this repository. Do not disclose
credentials, private documents, redaction values, or exploitable details in a
public issue.

Include the affected component and version, impact, reproduction steps using
synthetic data, and any suggested mitigation. Reports will be acknowledged as
soon as practical.
